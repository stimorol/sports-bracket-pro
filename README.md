# Sports Bracket Pro — 運動賽程表產生器與場邊平板數位記分板系統

> **線上正式版體驗 (Firebase Hosting)**：[https://hao-sports-bracket.web.app](https://hao-sports-bracket.web.app)  
> **版權所有**：`© 2026 Hao. GEG TAIWAN. All Rights Reserved.`（非商業教育與賽事分享授權）

結合 **React + Vite + Tailwind CSS** 模組化前端與 **Google Apps Script (Google Sheets)** 簡易雲端資料庫的零成本運動賽務管理系統。專為校園體育課、校慶運動會、系際盃、社團聯賽與民間運動賽事打造——**免架設付費伺服器，一台平板即可變身標準場邊大字數位記分板，完賽一鍵匯出 A4 正式比賽紀錄簽認單 PDF！**

---

## ✨ 核心功能亮點

### 1. 多元標準賽制與跨階段晉級
- **單淘汰制 (Single Elimination)**：自動計算最近 2 次方籤表、種子隊 (`Seed`) 標準交叉保護配位、選配季軍排名賽。
- **標準雙敗淘汰制 (Double Elimination)**：勝部各輪落敗者反向交叉進入敗部避免過早重逢，支援標準 **總冠軍驟死加賽 (`Bracket Reset`)**（勝部冠軍直落奪冠時自動免戰封王）。
- **多分組循環賽 (Round Robin)**：自動排程輪次、即時計算勝／和／敗積分與得失分差，支援跨階段勾選晉級決賽樹狀圖。
- **賽中免重置改隊名**：已開打賽事隨時修正隊伍名稱，完整保留既有比分與晉級路徑。

### 2. 九大運動專屬「場邊平板大字數位記分板」
點擊任一對戰卡片即可切換為滿版深色高對比記分板，支援 **遠距選手大字模式**、**螢幕恆亮防休眠 (`Screen Wake Lock API`)**、**電子蜂鳴器號角**、**45 步復原 (`Undo`)** 與 **系列賽多戰續記（單場決勝／3戰2勝／5戰3勝／7戰4勝）**：
- **匹克球 (`PICKLEBALL`)**：支援傳統 **雙打發球得分制 (`0 - 0 - 2` 開局三碼報分、1號／2號發球員自動輪轉、左右發球區站位提示)**、單打發球得分制與落地得分制 (`Rally`)。
- **籃球 (`BASKETBALL`)**：`Q1~Q4` 與 `OT` 延長賽、精準倒數大鐘 (`+1s / -1s`)、`+1 / +2 / +3` 快速加分、單節團犯 (`BONUS` 燈號，換節自動歸零)、剩餘暫停與球權方向。
- **羽球 / 排球 / 桌球 (`RACKET_SETS`)**：自動偵測 `局點 (Set Point)`、`賽末點 (Match Point)`、`Deuce`、羽球 BWF `30 分封頂`、決勝局中場換邊提醒；桌球支援每 2 球自動換發與 `10:10` 後每 1 球換發。
- **棒壘球 / 樂樂棒球 (`BASEBALL`)**：`N局上 ▲ / N局下 ▼`、逐局計分板 (`Box Score`)、`B / S / O` 好壞球出局圓燈（四壞保送、三振自動進位）。
- **躲避球 / 通用計時 (`TIMED_SETS`)**：倒數計時器 + 勝局累計 + 雙向加減分。
- **多戰系列賽完整支援**：所有運動（含籃球、棒壘球）在設定為 `3戰2勝 / 5戰3勝 / 7戰4勝` 時，每一戰皆可使用完整記分板，並支援 **「原地連續打下一戰」** 或 **「儲存本戰並暫離解鎖（跨時段／換平板續記下一戰）」**。

### 3. 正式比賽成績紀錄單（匯出 A4 PDF ／ 現場直接列印）
- 完賽前、完賽後或於頂部工具列點擊 **「比賽紀錄 PDF」**，即可產生標準 A4 單頁 **《正式比賽成績紀錄表》**。
- 自動帶入各節／各局比分明細、系列賽小分、總得分合計，支援填寫 **場地／桌次、紀錄員、主審裁判、賽務備註**，並附帶 **「雙方隊長簽認、紀錄員簽章、主審裁判簽章」** 四格核章欄。
- 支援 **單場獨立匯出**、**本階段全部已完賽批次匯出（一頁一場 A4）** 及 **賽前空白檢錄表列印**。

### 4. 多平板防撞互斥鎖與三種角色權限派發
- **單場次設備互斥鎖 (`MATCH_LOCKED`)**：任一紀錄組平板開啟該場次記分板後自動鎖定（12 分鐘自動續約），防止其他裝置誤改；若平板沒電斷線支援裁判強制接管。
- **三種專屬連線網址**：
  1. **主辦管理端（預設）**：完整編排賽程、抽籤、改隊名、晉級管理與雲端設定。
  2. **紀錄組平板專屬連結 (`?gas=...&mode=scorer`)**：僅能點開記分板計分與匯出紀錄單 PDF，**完全鎖定隱藏刪改賽程結構按鈕**。
  3. **選手／觀眾唯讀連結 (`?gas=...&mode=view`)**：手機掃描 QR Code 每 30 秒自動更新觀看即時局分與榮耀榜。

## 🚀 快速開始與雲端部署教學

### A. 本機測試與開發
```bash
# 安裝相依套件
npm install

# 啟動開發伺服器 (Vite HMR)
npm run dev

# 執行 19 項核心賽制、記分板狀態機與 GAS 後端單元測試 (Node.js v20+ 內建測試引擎)
npm test

# 打包生產環境靜態檔案至 dist/
npm run build
```
> Windows 使用者若僅需離線開啟，亦可直接執行 `npm start`（或雙擊 `啟動本地預覽伺服器.bat`）零套件啟動預編譯好的 `dist/`。

### B. 連結 Google 試算表雲端資料庫（選用，支援多平板即時同步）
> 💡 **萬用自適應架構**：同一份試算表範本**通吃全部 9 種運動與單淘汰／雙敗淘汰／循環賽**（首次上傳時系統會自動建立隱藏資料表與賽程／積分榜報表分頁，無須手動調整欄位）！建議**「每舉辦一場新盃賽，就建立一份新的試算表副本」**，即可獨立保存各屆成績。

1. **一鍵建立專屬試算表副本（推薦，已內建 GAS 程式碼）**：
   - 點擊 [**👉 點此建立「萬用賽事試算表範本」副本**](https://docs.google.com/spreadsheets/d/1FzM6Sy4cFkzWfKahzxes5gtv4ZzSACoFutu3uCeYosI/copy)（或開啟系統內「設定雲端同步」點擊引導按鈕）。
   - *備用方案*：若您想使用自己的空白 Google 試算表，請點選「擴充功能 ➔ Apps Script」，將本專案根目錄 [`google_apps_script.js`](./google_apps_script.js) 完整程式碼貼上取代預設內容並儲存（系統雲端設定視窗亦提供一鍵複製程式碼按鈕）。
2. 在建立好的試算表副本上方選單點選 **「擴充功能」➔「Apps Script」**，再點選右上角 **「部署」➔「新增部署作業」**：
   - 類型：**網頁應用程式 (Web App)**
   - 執行身分：**我 (Me)**
   - 誰可以存取：**所有人 (Anyone)**
   - *首次授權提示*：若出現「Google 尚未驗證此應用程式」，請點選左下角 **「進階」➔「前往…(不安全)」➔「允許」**。
3. 複製產生的 `https://script.google.com/macros/s/.../exec` 網址，貼入系統 **「設定雲端同步」** 並點擊 **「測試連線」** 驗證成功後，即可上傳賽程並派發紀錄組平板連結與觀賽連結！

### C. 部署為正式網站（Firebase Hosting 或 GitHub Pages）
- **Firebase Hosting**：專案已內建 [`firebase.json`](./firebase.json)，執行 `npx firebase-tools login` 與 `npx firebase-tools deploy --only hosting` 即可發布。
- **GitHub Pages**：專案已內建 [`.github/workflows/deploy-github-pages.yml`](./.github/workflows/deploy-github-pages.yml)，於 GitHub 儲存庫 `Settings > Pages > Source` 選擇 `GitHub Actions`，每次推送至 `main` 分支即自動測試並部署。
